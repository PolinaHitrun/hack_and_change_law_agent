Бэкенд может возвращать doc_id и массив highlights (точные подстроки или номера пунктов), которые автоматически подсвечиваются в боковом документе.

        

        
      


      

        

          
          
        


        

          
Контракт ответа бэкенда для открытия файла сбоку и выделения текста:

          

            

              POST /api/chat
              

                Ответ JSON:
                
{
  "reply": "Срок согласования юротделом — 3 рабочих дня, главбухом — 2 рабочих дня (п. 2.2).",
  "citations": [
    {
      "doc_id": "kb-meridian-2025",
      "clause": "Пункт 2.2",
      "highlight_text": "2.2. Срок согласования юридическим отделом — 3 (три) рабочих дня, главным бухгалтером — 2 (два) рабочих дня.",

    }
  ]
}

              

            

            

              JS API window.MusyatkiBankAPI.openKnowledgeBaseHighlight({ docId, highlightText, clause })
